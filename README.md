# Smart EMI & Loan Repayment Planner

A simple one-page website for the Financial Literacy and Banking (FLB) project.

## How to open it

Double-click `index.html`. It opens in Chrome or Edge, and needs no internet or installation.

## Features

- Enter your loan details
- Your EMI
- Can you afford it?
- Save with extra payments
- Year-by-year repayment

## Files

- `index.html`: the page
- `style.css`: colours and layout
- `script.js`: all the calculations
